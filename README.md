# 시냅스 아레나 (Synapse Arena)

뉴런(점)과 시냅스(선)를 직접 이어 가며 **AI를 기초부터** 배우는 게임입니다.
뉴런 하나로 논리 게이트를 만들고, 그 뉴런들로 생명체를 움직이고, 마지막에는 뉴런이 스스로 배우게 합니다.
같은 뇌는 언제나 같은 결과를 냅니다. 운 요소는 없습니다.

**플레이:** https://hjh202602-blip.github.io/synapse-arena/

## 실행

설치할 것은 없습니다. `index.html`을 브라우저로 열면 됩니다.
로컬 서버로 열고 싶다면:

```bash
python -m http.server 5640 --bind 127.0.0.1
```

그다음 http://127.0.0.1:5640 을 엽니다.

## 두 갈래

문제는 두 갈래로 나뉩니다. 잠금과 이전·다음은 갈래 안에서만 이어집니다.

### AI 배우기 (개념 설명)

| 장 | 실험 | 배우는 개념 |
|---|---|---|
| 0장 시작하기 | 0-1 튜토리얼 | 화면 안내를 따라 모든 조작을 하나씩 |
| 1장 뉴런 하나 | 1-1 따라 하기 · 1-2 OR · 1-3 AND · 1-4 NOT · 1-5 XOR | 가중치 → 가중합 → 문턱과 편향 → 음수 가중치 → 다층 퍼셉트론 |
| 2장 스스로 배우는 뇌 | 2-1 스스로 배우기 · 2-2 학습률 · 2-3 한 뉴런의 한계 · 2-4 역전파 | 학습(델타 규칙) → 학습률 → 한 층의 한계 → 역전파 |
| 3장 보상으로 배우는 뇌 | 3-1 칭찬하기 · 3-2 조금씩 칭찬하기 · 3-3 벌점 · 3-4 점수의 함정 | 강화학습: 보상 → 보상 쪼개 주기 → 벌점 → 보상 해킹, 탐험과 활용 |

3장(강화학습)은 방식이 다릅니다. 뇌를 직접 잇지 않고 **무엇에 몇 점을 줄지(보상 설계)**만 정합니다. 생명체는 세대마다 뇌를 조금씩 바꾼 후보 6개를 시험해서 점수가 더 높은 뇌를 남기는 시행착오로 배우고, 세대마다 진짜 목표로 시험을 봅니다. 처음 열면 이 방식 전용 안내가 나옵니다.

### 사고력 퍼즐 (논리·사고 연습)

| 장 | 퍼즐 | 기르는 생각 |
|---|---|---|
| 1장 논리 회로 퍼즐 | 1-1 조건 걸기 · 1-2 같을 때만 · 1-3 다수결(3입력) · 1-4 셋 중 하나만 · 1-5 반가산기(출력 2개) · 1-6 +1과 -1만으로(NAND) | 조건 쪼개기, 경우 나누기, 세어서 비교하기, 분할 정복, 적은 부품으로 조립하기 |
| 2장 생명체 길찾기 | 2-1 첫 발걸음 ~ 2-7 아귀 | 감각을 바퀴에 이어 규칙 설계하기(교차 연결, 반사, 억제, 수염, 히든 뉴런 문) |

- 1장: 진리표의 모든 줄을 맞히는 뇌를 만들고 채점합니다. 줄을 누르면 그 입력일 때 뇌가 어떻게 반응하는지 보입니다.
- 2장: 눈·더듬이·수염을 바퀴에 이어 생명체가 먹이를 찾게 합니다.
- 3장: 가중치는 직접 못 바꿉니다. 학습률을 고르고 학습시키면, 오차 그래프와 함께 가중치가 스스로 바뀝니다.

모든 실험(학습 실험 제외)에는 처음부터 히든 뉴런 2개가 있습니다. 쓰고 싶을 때 선만 이으면 됩니다.
2장과 3장을 처음 열 때도 그 화면의 기능 안내가 나옵니다(설정 → 기능 안내 다시 보기).

### 활성화 함수와 논리 게이트

히든·출력·바퀴 뉴런을 클릭하면 활성화 함수를 고를 수 있습니다.

| 어디서 | 고를 수 있는 함수 |
|---|---|
| 0~1장, 3장 | 0~1 자르기(기본)만. 1장은 게이트를 뉴런으로 직접 만드는 장이라서 |
| 2장 | 0~1 자르기, ReLU, 선형, 계단, 시그모이드, tanh |
| 연구실·대결 | 위 함수 + AND·OR·NOT·XOR 게이트, 소프트맥스 |
실험을 깨면 개념 노트에 카드가 열립니다. 카드마다 같은 개념을 **뇌과학 쪽**과 **AI 쪽**에서 설명합니다.

## 힌트와 정답

힌트는 세 단계입니다: 개념 → 값 조절(값을 키우거나 줄이면 어떻게 되는지) → 거의 답.
힌트를 다 열면 **정답 보기**가 나타나고, "정말 정답을 보시겠습니까?"에 예를 누르면 정답 뇌(학습 실험은 추천 학습률)를 보여 줍니다. 정답 뇌는 Ctrl+Z로 되돌릴 수 있습니다.

실험 화면 위의 **◀ 이전 / 다음 ▶**으로 실험 사이를 오갈 수 있습니다(다음은 지금 실험을 깨야 열립니다).

## 뇌의 규칙

- 뉴런 값 = 들어온 (보내는 뉴런 값 × 가중치)의 합을 0~1로 자른 것.
- 상시 뉴런은 언제나 1 → 여기에 붙은 가중치가 편향(문턱)이다.
- 출력 뉴런은 0.5 이상이면 1로 읽는다.
- 히든 뉴런: 입력에서 신호를 받아 다른 뉴런에게만 넘기는 중간 뉴런. 0 아래로 내려가지 않아서 "문" 역할을 할 수 있다.
- 학습: 가중치 변화 = 학습률 × (목표 − 출력) × 입력. 히든 뉴런이 있으면 오차를 거꾸로 나눠 준다(역전파).

## QA

```bash
node tests/qa-sim.js
```

- 모든 실험이 정답 뇌(또는 추천 학습률)로 풀리고 별 3개를 받는지
- 빈 뇌나 쉬운 꼼수로는 안 풀리는지, 정답 주변 값으로도 대부분 풀리는지
- XOR이 히든 뉴런 없이는 어떤 가중치로도 안 풀리는지, 한 뉴런은 어떤 학습률로도 XOR을 못 배우는지
- 같은 입력이면 같은 결과가 나오는지, 라이벌 난이도 순서가 맞는지
