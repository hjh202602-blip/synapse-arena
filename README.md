# 시냅스 아레나 (Synapse Arena)

뉴런(점)과 시냅스(선)를 직접 이어 가며 **AI를 기초부터** 배우는 게임입니다.
뉴런 하나로 논리 게이트를 만들고, 그 뉴런들로 생명체를 움직이고, 마지막에는 뉴런이 스스로 배우게 합니다.
같은 뇌는 언제나 같은 결과를 냅니다. 운 요소는 없습니다.

**플레이:** https://hjh202602-blip.github.io/synapse-arena/

## 실행

설치할 것은 없습니다. `index.html`을 브라우저로 열면 됩니다.
로컬 서버로 열고 싶다면:

```bash
python -m http.server 5640 --bind 127.0.0.1
```

그다음 http://127.0.0.1:5640 을 엽니다.

## 배우는 순서

모든 실험은 한 목록(AI 배우기)에 있고, 장마다 **분류 태그**가 붙어 있습니다. 목록 위의 분류 버튼으로 "AI 개념"이나 "사고력"만 골라 볼 수 있습니다.

| 장 | 태그 | 실험 | 배우는 것 |
|---|---|---|---|
| 0 시작하기 | AI 개념 | 0-1 튜토리얼 | 화면 안내를 따라 모든 조작을 하나씩 |
| 1 뉴런 하나 | AI 개념 | 따라 하기 · OR · AND · NOT · XOR | 가중치 → 가중합 → 문턱과 편향 → 음수 가중치 → 다층 퍼셉트론 |
| 2 논리 회로 퍼즐 | 사고력 | 조건 걸기 · 같을 때만 · 다수결 · 셋 중 하나만 · 반가산기 · +1과 -1만으로 | 조건 쪼개기, 경우 나누기, 분할 정복, 적은 부품으로 조립하기 |
| 3 생명체 길찾기 | 사고력 | 첫 발걸음 ~ 아귀 (7개) | 감각을 바퀴에 이어 규칙 설계하기 |
| 4 스스로 배우는 뇌 | AI 개념 | 스스로 배우기 · 학습률 · 한 뉴런의 한계 · 역전파 | 학습(델타 규칙) → 학습률 → 한 층의 한계 → 역전파 |
| 5 보상으로 배우는 뇌 | AI 개념 | 칭찬하기 · 조금씩 칭찬하기 · 벌점 · 점수의 함정 | 강화학습: 보상 → 보상 쪼개 주기 → 벌점 → 보상 해킹 |
| 6 점을 나누는 뇌 | AI 개념 | 선 하나로 나누기 · 비스듬한 선 · 가운데 띠 · 동그라미 안쪽 · 외우지 말고 이해하기 · 선을 스스로 찾기 | 분류: 결정 경계 → 가중치와 편향이 선을 움직이는 법 → 선을 겹쳐 모양 만들기 → 과적합과 시험 데이터 → 경사 하강법 |
| 7 그림을 보는 뇌 | AI 개념 | 세로줄 찾기 · 가로줄 찾기 · 어두움에서 밝음으로 · 세로일까 가로일까 | CNN의 기초: 필터(합성곱) → 특징 맵 → 경계 찾기 → 풀링과 분류 |
| 8 기억하는 뇌 | AI 개념 | 방금 전 기억하기 · 한 번이라도 켜졌나 · 두 번 연속 · 두 칸 전 기억하기 · 홀짝 세기 | RNN의 기초: 되먹임 → 기억 붙잡기 → 순서 패턴 → 긴 기억의 어려움(LSTM) → 상태로 세기 |
| 9 스스로 묶는 뇌 | AI 개념 | 끼리끼리 묶기 · 평균으로 옮기기 · 시작이 중요해 · 몇 무리일까 | 비지도 학습: 군집화 → k-평균 → 지역 최소 → 팔꿈치로 무리 수 고르기 |
| 10 압축하는 뇌 | AI 개념 | 둘을 하나로 · 넷을 둘로 · 잡음 지우기 · 스스로 압축 배우기 | 오토인코더: 인코더·디코더 → 잠재 공간 → 잡음 제거 → 표현 학습 |

5장(강화학습)은 방식이 다릅니다. 뇌를 직접 잇지 않고 **무엇에 몇 점을 줄지(보상 설계)**만 정합니다. 생명체는 세대마다 뇌를 조금씩 바꾼 후보 6개를 시험해서 점수가 더 높은 뇌를 남기는 시행착오로 배우고, 세대마다 진짜 목표로 시험을 봅니다. 화면 맨 위에 생명체(에이전트)가 크게 나오고, 휠로 내리면 점수 규칙과 뇌가 있습니다. 학습 배속(1×~8×)을 고를 수 있습니다.

6장은 진리표 대신 **점 그래프**가 나옵니다. 입력은 점의 x·y 좌표이고, 배경색은 평면의 모든 자리에서 뇌가 내는 답, 흰 선은 결정 경계입니다. 점을 누르면 그 점일 때 뇌 값이 왼쪽에 보입니다. 5번째 실험은 훈련 데이터의 잡음 섞인 점을 다 맞히는 게 아니라, 채점 때 처음 보는 **시험 데이터**를 90% 이상 맞혀야 합니다.

7장은 뇌 편집기 대신 **필터 편집기**가 나옵니다. 3×3 칸을 눌러 +1/-1을 칠하고(휠 ±0.5, 우클릭 0) 편향을 정하면, 6×6 그림 위에 필터를 겹쳐 계산한 4×4 특징 맵이 바로 보입니다. 마지막 실험은 필터 두 개 → 최댓값(풀링) → 출력 뉴런으로 그림을 분류합니다.

8장은 진리표 대신 **시간표**가 나옵니다. 입력이 왼쪽 칸부터 한 칸씩 들어오고, 기억 뉴런(↺)에는 히든 뉴런이나 출력이 바로 전 칸에 낸 값이 되돌아옵니다(뇌 편집기의 점선 화살표). 새 순서(줄)가 시작되면 기억은 0으로 비워집니다.

9장은 정답 색이 없는 **점 지도**가 나옵니다. 중심을 끌어서 옮기거나, "한 걸음"(묶기 → 옮기기)으로 k-평균을 한 단계씩 돌립니다. 거리 합이 작을수록 잘 묶인 것이고, 마지막 실험은 중심 수 k를 고르며 k별 거리 합(팔꿈치)을 봅니다.

10장은 입력을 출력에 바로 이을 수 없고 가운데 히든 뉴런(코드)을 거쳐야 합니다. 진리표에 "코드" 칸과 **코드 지도**(잠재 공간)가 붙어서, 입력마다 코드가 어디에 놓이는지 볼 수 있습니다.

모든 실험 화면 위의 **? 안내 다시 보기**로 그 화면의 사용 안내를 다시 볼 수 있습니다.

### 활성화 함수와 논리 게이트

히든·출력·바퀴 뉴런을 클릭하면 활성화 함수를 고를 수 있습니다.

| 어디서 | 고를 수 있는 함수 |
|---|---|
| 0~1장, 3장 | 0~1 자르기(기본)만. 1장은 게이트를 뉴런으로 직접 만드는 장이라서 |
| 2장, 6장(4번째 실험까지) | 0~1 자르기, ReLU, 선형, 계단, 시그모이드, tanh |
| 연구실·대결 | 위 함수 + AND·OR·NOT·XOR 게이트, 소프트맥스 |
실험을 깨면 개념 노트에 카드가 열립니다. 카드마다 같은 개념을 **뇌과학 쪽**과 **AI 쪽**에서 설명합니다.

## 힌트와 정답

힌트는 세 단계입니다: 개념 → 값 조절(값을 키우거나 줄이면 어떻게 되는지) → 거의 답.
힌트를 다 열면 **정답 보기**가 나타나고, "정말 정답을 보시겠습니까?"에 예를 누르면 정답 뇌(학습 실험은 추천 학습률)를 보여 줍니다. 정답 뇌는 Ctrl+Z로 되돌릴 수 있습니다.

실험 화면 위의 **◀ 이전 / 다음 ▶**으로 실험 사이를 오갈 수 있습니다(다음은 지금 실험을 깨야 열립니다).

## 뇌의 규칙

- 뉴런 값 = 들어온 (보내는 뉴런 값 × 가중치)의 합을 0~1로 자른 것.
- 상시 뉴런은 언제나 1 → 여기에 붙은 가중치가 편향(문턱)이다.
- 출력 뉴런은 0.5 이상이면 1로 읽는다.
- 히든 뉴런: 입력에서 신호를 받아 다른 뉴런에게만 넘기는 중간 뉴런. 0 아래로 내려가지 않아서 "문" 역할을 할 수 있다.
- 학습: 가중치 변화 = 학습률 × (목표 − 출력) × 입력. 히든 뉴런이 있으면 오차를 거꾸로 나눠 준다(역전파).

## QA

```bash
node tests/qa-sim.js
```

- 모든 실험이 정답 뇌(또는 추천 학습률)로 풀리고 별 3개를 받는지
- 빈 뇌나 쉬운 꼼수로는 안 풀리는지, 정답 주변 값으로도 대부분 풀리는지
- XOR이 히든 뉴런 없이는 어떤 가중치로도 안 풀리는지, 한 뉴런은 어떤 학습률로도 XOR을 못 배우는지
- 같은 입력이면 같은 결과가 나오는지, 라이벌 난이도 순서가 맞는지
- 0~10장 모든 실험이 "정답 보기" 답으로 별 3개를 받고, 빈 답(빈 뇌·빈 필터·처음 자리)으로는 안 풀리는지
- 힌트에 적은 수치(학습률별 학습 횟수, 걸음 수, 거리 합)와 "이렇게 하면 안 된다"는 말이 실제와 같은지
